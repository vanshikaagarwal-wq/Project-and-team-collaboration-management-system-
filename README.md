# Project and Team Collaboration Management System
HTML + CSS + JS frontend with json-server backend.
## Run
npm install && npm start  ->  http://localhost:3000/login.html
Demo login: admin@test.com / 123456
## Features
Auth (signup/login/logout/session guard) | Dashboard stats | Project CRUD with progress | Task board with assignee, priority, status | Profile edit, team list, comments
